# Work_Review v1.1.4-rc.1 (English)

First release candidate for 1.1.4, for testing only. It does not replace stable `1.1.3` as Latest and is not offered through the default stable update channel. Download and install this RC manually for the first trial. After installation, optionally enable **Receive test versions** on About to receive newer candidates. Back up your data; use disposable data to test upgrades and cleanup.

### Fixed
- **Optional test updates**: a compact, disabled-by-default checkbox reuses the single check button. Manual updates show the exact version before downloading; test versions additionally warn about instability and backups. Full SemVer ordering distinguishes RC numbers and stable versions, prevents downgrades, and pins downloads to the confirmed tag. The executable, installer and updater manifest report the same full RC version.
- **Update package integrity**: preserve Tauri signature verification and additionally compare downloaded bytes against the target asset's SHA-256 from GitHub's official HTTPS API before running an installer. A mirror cannot substitute an older validly signed package just by relabeling its version and URL. Missing or mismatched official digests fail closed; mirror-supplied digests are not trusted.
- **Simpler About controls**: remove the separate three-column update panel, duplicate versions, channel badges and expanded details. Preserve the brand, original actions, auto-check setting, progress and failure feedback.
- **Windows standby accounting** (#189): split activity at suspend/resume and session display-state boundaries, backed by independent sampling and dual-clock checks. Preserve only the continuously observed pre-suspend tail; never fill an unknown gap with work time. New/merged records, disabled screenshots and floating-window timing respect the boundary. Discard screenshots that cross a standby transition.
- **Report editor font** (#188): inherit the interface font by default and add an appearance preference for common proportional or monospace fonts. Unavailable fonts fall back to the interface font.
- **GNOME Wayland idle time** (#187): query Mutter IdleMonitor first, retaining fallback providers for other desktops.
- **Activity API privacy**: lists and individual records share privacy filtering; invalid dates cannot expand to an all-history query. Bound request-read time and concurrent local API connections.
- **Data reliability**: stage data-directory migration before replacing existing target data, preserve its recovery path, propagate real database migration failures, and do not report failed activity backfills as successful. Editing a fallback yesterday report updates its actual date and cache entry.
- **Screenshots and storage**: capture outside the global application-state lock with bounded external commands. Clearing expired or excess local images also clears stale database paths while retaining remote URLs. Remote S3 and WebDAV require HTTPS except for local/private-network HTTP.
- **Linux background usage**: share a short-lived idle cache, bound command execution, reduce lock/window polling and duplicate process queries, and reduce unnecessary input-bridge/retry wakeups when the avatar is off.
- **Queries and UI feedback**: index normalized browser URLs, reuse a batch's browser history during AI classification, and remove duplicate timeline preloading. Pagination, overview breakdown and week-strip failures are distinct from empty data. Narrow navigation has accessible names and current-page semantics.
- **Release gates and documentation**: dependency audits run for every PR and main push; update TLS trust dependencies, correct Windows artifact paths, and validate all five version sources before release.

### Safe defaults and validation limits
- This release does **not** rewrite incorrectly recorded historical durations. The unexpected application name reported in #189 needs separate evidence and is not established as fixed.
- Automated checks, builds and native notification registration are not real S0/S3 sleep/wake or installer-upgrade acceptance. Windows/macOS/Linux long-running desktop testing remains incomplete. See [standby acceptance steps](../testing/windows-standby.md). Some global input hooks still ignore events while disabled instead of being physically unregistered.
- Online installation stops safely if the official asset digest is absent, the GitHub API is unavailable or rate-limited, or downloaded bytes do not match. Retry later or download manually from the release page. Linux still uses manual installation from the selected release page.
- macOS remains ad-hoc signed and may require permissions again after updating. The avatar rendering issue after freeze recovery (#177) is not confirmed resolved.
- Automatic metadata cleanup stays disabled by default. `0` days means keep forever, and WebDAV sync does not override this device's cleanup authorization or retention period.

### macOS install note
If macOS reports the app as damaged on first launch, run:

```bash
sudo xattr -rd com.apple.quarantine '/Applications/Work Review.app'
```
