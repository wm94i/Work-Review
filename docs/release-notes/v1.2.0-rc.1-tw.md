# v1.2.0-rc.1

1.2.0 的第一個候選版本，彙整隱私與安全強化、效能與可靠性改善、新報告功能及 Svelte 5 遷移。僅供測試，不取代正式版 `1.1.3` 的 Latest。升級、遷移目錄或還原備份前，請完整備份資料目錄。

### 新增功能

- **專案工時歸集**：依應用程式、視窗標題、網域、URL 路徑或執行檔規則歸集活動，提供規則預覽、專案統計、時間軸快捷建立規則、報告上下文、本機 API 與 Agent 工具；隱私規則優先。
- **匯出與備份還原**：活動與每日統計支援 CSV / JSON 匯出，套用目前隱私規則並防止試算表公式注入。目錄備份包含一致 SQLite 快照與 SHA-256 清單；還原前檢查檔案及 Schema 相容性、建立安全備份，替換失敗時回復。
- **週報與月報**：報告頁可切換日／週／月，檢視趨勢及專案、應用程式、分類投入，並匯出 Markdown；支援簡中、繁中、英文與阿文。
- **隱私預設值**：預設略過可辨識的無痕／隱私視窗；設定排除網域但無法取得瀏覽器 URL 時，預設採匿名化處理。
- **增量語意索引**：新增資料沿游標追加，更新或刪除只重建受影響日期；可選背景自動索引預設關閉。
- **Bot 唯讀自然語言問答**：Telegram、飛書、釘釘與企業微信已授權傳送者可使用本機啟用的問答模式，附傳送者配額與併發上限，不提供寫入或聯網工具。
- **工作流程整合**：專注與上下文切換指標、本機 Git 提交關聯、Obsidian frontmatter 與管理區塊增量匯出、依任務分流模型，以及報告、摘要、專案與待辦 Agent 工具。

### 隱私與安全

- WebDAV 同步升級至 v2，只上傳白名單偏好並單向收緊隱私規則；不包含 API Key、密碼、Bot Token、模型端點或本機清理授權，並清除遠端舊快照中的敏感欄位。
- 本機 API、MCP、助手工具、報告及活動匯出統一套用目前隱私規則；預設限制 OCR、截圖路徑、執行檔路徑及活動搜尋摘要。
- Windows 截圖在儲存、OCR 與上傳前遮蔽受保護的可見視窗，無法遮罩時略過截圖；macOS / Linux 保留前景應用程式判斷。
- 飛書、釘釘與企業微信要求傳送者綁定；Bot 共用授權、防重放、去重、配額及有界路由。
- 強化 SSRF、重新導向、憑證遮蔽、匯出路徑、日期、WebView 導航、CSP、前端權限及外部連結。

### 效能與可靠性

- SQLite WAL 唯讀連線、索引範圍查詢、增量回收與局部失效，減少資料庫工作及鎖競爭。
- 阻塞 I/O 與影像處理移出共用狀態鎖及非同步工作執行緒；Windows OCR 與瀏覽器 UI Automation 重用專用工作執行緒和快取。
- 改善截圖雜湊、縮圖快取、活動合併、閒置採樣、活動尾段計時、背景監督及 Rust 自動日報排程。
- Rust 主入口拆分為職責明確的模組；前端遷移 Svelte 5，加入元件行為測試及 AST 安全不變量檢查。

### 修復

- Obsidian 增量匯出讀取舊筆記失敗時立即停止，寫入使用原子替換，避免讀寫失敗損壞手寫內容。
- 隱私規則變更時以同一交易清空小時摘要與所有語言的週／月報快取；清理失敗則中止儲存設定，生成期間規則變更也不能寫回舊結果。
- 更新預設模型：OpenAI `gpt-6.2-sol`、Gemini `gemini-4-hydrogen`、DeepSeek `deepseek-flash`、Qwen `qwen3.8-flash`、Kimi `kimi-k3`、MiniMax `MiniMax-M3.1-Flash`；OpenAI 推理請求改用相容的 token／採樣參數及任務預算。AI 日報回傳空內容時退回基礎範本並說明原因。
- 修復 UTF-8 串流邊界、企業微信填充、夏令時間排程、時間軸縮圖更新、輪詢間隔持久化及舊設定整份寫回。

### 相容性與驗證邊界

- SQLite Schema 升至 `user_version = 3`，新備份不能直接還原至舊客戶端。所有裝置升級後再開啟 WebDAV v2 同步；舊客戶端會拒絕新格式，且仍可能上傳敏感欄位。
- 飛書、釘釘與企業微信成員需先綁定才能查詢。背景自動索引與 Bot 自然語言問答預設關閉，活動中繼資料清理仍需本機明確啟用。
- 既有安裝版可在關於頁開啟「接收測試版」；便攜版與 Linux 從所選版本發布頁手動更新。更換便攜程式時保留原 `Data`。
- 本機 Windows 已通過 795 項 Node 測試、20 項元件測試、905 項 Rust 測試，以及型別檢查、前端正式建置、格式與 Clippy 零警告檢查；2 項 Rust 測試仍忽略。發布產物須通過本次標籤的五平台建置、簽章及附件門檻。
- 實際安裝升級、跨電腦便攜啟動、長時間 OCR／採集、Windows 真實待機及 macOS／Linux 桌面互動仍待驗證。macOS 保留 ad-hoc 簽章，更新後可能需要重新授權。
- 截圖遮罩僅 Windows，且仍有透明浮層限制；Bot 群組回覆對全群可見。搜尋詞仍傳送到設定的搜尋服務，使用系統代理時重新導向保留已記錄的位址檢查限制。
