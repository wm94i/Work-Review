# v1.2.1

維護更新，重點提升桌寵穩定性與啟動效能、完善助手擴展（Personal Agent Harness）執行語意與安全邊界，並最佳化時間線詳情互動與 Windows 瀏覽器網址採集。

### 助手擴展（Personal Agent Harness）可靠性與安全

- **自主任務狀態語意修正**：修復設定可用 AI 模型但呼叫失敗降級時仍被誤報 `completed` 的問題；綁定個人技能的自主任務在缺少可用 AI 模型（例如未授權雲端模型）時明確回報 `failed` 並說明原因；透傳帳本 `timed_out` / `failed` / `cancelled` 終態，未授權雲端模型降級為本機統計時於摘要中明確標註；每日定時判定改用 `.earliest()` 避免夏令時歧義。
- **個人技能建議工具生效與邊界加固**：`allowed_tools`（相容 `allowed-tools` 連字號寫法並校驗工具名稱）現會注入技能目錄提示詞與 `load_skill` 正文，同時中和正文內嵌的偽造開始／結束邊界前綴。
- **外部 MCP 探索快取與脫敏**：桌面工作復盤的外部 MCP 探索新增短時 TTL 快取（命中 60 秒、空結果／離線 20 秒），以 `(data_dir, blocked_self_port, enabled_servers)` 的 SHA-256 指紋校驗（快取鍵不滯留明文 Token，讀取過期項即時清除），並於儲存、刪除或連通性測試完成後主動失效。
- **非同步帳本、逾時狀態與產物邊界修復**：`RunLedgerRecorder` 熱路徑 SQLite 寫入移入 `tokio::task::spawn_blocking` 並記錄任務異常告警；請求時長預算耗盡觸發兜底文案時正確記錄 `RunStatus::TimedOut`；上下文壓縮估算同時計入 assistant 文字與 `tool_calls`；`read_run_artifact` 依原始來源工具採 fail-closed 信任邊界且不重複包裹。

### 修復與體驗

- 擴大 Windows 瀏覽器網址列 UIA 搜尋深度並略過網頁內容樹，修復預設深度不足導致的 Chrome 網址漏採，同時維持 350ms 逾時與快取保護。
- 未設定 AI 時不再將舊版 Ollama / Qwen3 預設自動遷移為模型檔案；既有明確儲存的模型維持相容遷移。
- 時間線詳情改採截圖畫布與扁平資訊側欄，提供網址複製、截圖放大、分類與專案操作及底部刪除入口，並適配深色主題、窄視窗與鍵盤焦點約束。
- 助手介面統一改稱「助手擴展」，同步四種介面語言、功能說明與三份 README。

### 桌寵可靠性與效能

- 修復點擊穿透、隱藏本體開關未儲存，以及設定快照覆寫拖曳位置與待跟進項；重複「記住」不再重複寫入。
- 輸入監聽依生命週期啟停並維持代次隔離；修正 Windows 標點與編輯鍵映射，隱藏本體時清理按鍵狀態並減少空閒喚醒。
- Windows 鍵盤 Hook 改用預分配非阻塞佇列與原子滑鼠匯聚，避免低階回呼等待鎖。
- Linux Xlib 多執行緒初始化前移至 GUI 啟動前並校驗結果；穿透更新未送達或失敗時使快取失效以便重試。
- 主動 AI 於獨立任務套用截止時間與未設定模型退避，工作階段查詢移入阻塞執行緒並複用含隱私簽名的快取，跟進提示後的靜默期跨幀生效。
- 展開與收合保留精簡位置、跳過相同尺寸重設、取消過期尺寸校正計時器，並於拖曳結束後依目前位置計算氣泡方向。
- 桌寵改採獨立透明頁面入口（`avatar.html`），避免啟動時載入主視窗路由與側欄；隱藏視窗暫停動畫、複用預計算貝茲係數並為 Windows 透明恢復提供有界重試。
