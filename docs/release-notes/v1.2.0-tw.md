# v1.2.0

正式發布，彙整 1.2.0-rc.1 的隱私、效能、報告、匯出與 Svelte 5 改進，並加入個人 Agent 工作流程。既有 RC 發布與標籤保留。升級前請備份完整資料目錄。

### 個人 Agent 工作流程

- **執行追蹤**：在「工作助手 → 引擎與技能」查看狀態、工具審批、資料邊界、上下文壓縮與事件。大型工具結果暫存於目前執行內並按需讀取。
- **個人技能**：建立、編輯或刪除本機 `skills/<name>/SKILL.md`，僅於工作復盤模式按需載入。
- **唯讀自主任務**：支援每日定時、15–1440 分鐘間隔及手動執行，應用程式持續執行時依序調度。預設使用本機統計或回環模型，單一任務明確允許後才將隱私過濾的記錄傳送至雲端模型。
- **外部 HTTP MCP**：僅桌面工作復盤模式使用，每次工具呼叫均須人工確認；一般聊天、Bot 與自主任務不接入。公網端點須 HTTPS，回環存取須明確允許。支援初始化、會話、JSON / SSE 與會話重建，工具輸出視為不可信內容。

### 相對 1.1.3 的主要更新

- 專案工時歸集、專注與上下文切換指標、Git 提交關聯、Obsidian frontmatter / 管理區塊及依任務分流模型。
- 四語日／週／月復盤、CSV / JSON 匯出、SHA-256 備份驗證、安全還原回復、增量語意索引及可選 Bot 唯讀問答。
- WebDAV 同步 v2 僅共享白名單偏好與更嚴格的隱私規則；加入傳送者綁定、Windows 截圖遮罩、憑證清洗及 WebView／助手出站限制。
- SQLite WAL、範圍查詢、常駐 Windows OCR／UIA、截圖與活動計時改善、背景監督及 Svelte 5 遷移。
- Linux／macOS 編譯修復，`cookie` 升至 0.18.3、`url` 升至 2.5.9，納入對應 RustSec 修復。

### 最終修復

- 還原及安全回復時原位保留本機技能、自主任務、MCP 設定、Token、隱藏素材與技能空目錄。
- 回環模型連線固定回環位址並禁用代理及自動重新導向，涵蓋串流、非串流與回退請求。
- Run 帳本輸入／錯誤摘要及任務摘要，先完整清洗含空格與跳脫字元的引號憑證，再執行隱私過濾。
- MCP SSE 收到符合請求 ID 的完整事件後立即回傳，不必等待連線結束；保留會話、體積與期限檢查。
- 包含 RC 的 Obsidian 原子匯出、隱私快取失效、推理模型相容、UTF-8 串流、排程及設定持久化修復。

### 升級與驗證邊界

- SQLite 自動遷移至 Schema 4，加入本機 Run／事件／審計帳本。新資料庫及備份不能直接用於舊客戶端；回退時請還原升級前備份。
- 飛書、釘釘與企業微信成員需先綁定。所有裝置升級後再開啟 WebDAV v2。自動索引、Bot 自然語言問答、中繼資料清理與任務雲端授權均預設關閉。
- 資料目錄遷移攜帶技能、自主任務與 MCP 設定。應用程式內備份僅包含資料庫、應用設定及可選截圖；請另行安全備份 `skills/`、`agent_routines.json`、`mcp_clients.json`，還原保留目標機器的這些檔案。修改 MCP 端點會清除舊 Token。
- Windows 與 macOS 安裝版沿用正式版更新入口；Linux 與便攜版從發布頁手動更新，更換便攜 EXE 時保留原 `Data`。
- 本機 Windows 已通過 800 項 Node、20 項元件、944 項 Rust 測試，以及型別、正式建置、格式、warnings-denied check 與 Clippy；另 2 項 Rust 測試忽略。發布須通過目前提交的跨平台 CI、安全審計與五平台產物、簽章、附件及 Linux GLIBC 門檻。
- 實際安裝升級、跨電腦便攜啟動、長時間 OCR／採集、Windows 真實待機、macOS／Linux 真機互動及第三方 MCP 尚未完成全面桌面驗收。
- 截圖遮罩僅 Windows，仍有透明浮層限制。macOS 保留 ad-hoc 簽章，可能需重新授權。搜尋詞傳送到設定服務，Bot 群組回覆對全群可見；聯網工具的代理重新導向保留 RC 記錄中的限制。
