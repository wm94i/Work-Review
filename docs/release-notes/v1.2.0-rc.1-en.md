# v1.2.0-rc.1

First release candidate for 1.2.0, combining privacy and security hardening, performance and reliability work, new reporting features, and the Svelte 5 migration. This is a test release and does not replace stable `1.1.3` as Latest. Back up the complete data directory before upgrading, migrating storage, or restoring a backup.

### New features

- **Project time tracking:** classify activities into projects using application, window title, domain, URL path, or executable rules. Includes rule previews, project statistics, timeline shortcuts, report context, a local API endpoint, and an Agent tool. Privacy rules take priority.
- **Exports and backups:** export activities and daily statistics as CSV or JSON with current privacy filtering and spreadsheet formula protection. Create directory backups with SQLite snapshots and SHA-256 manifests; restore validates files and schema compatibility, creates a safety backup, and rolls back failed replacement.
- **Weekly and monthly reviews:** switch between day, week, and month in Reports, inspect trends and project/application/category totals, and export Markdown. Supports Simplified Chinese, Traditional Chinese, English, and Arabic.
- **Privacy defaults:** skip recognized private/incognito windows by default. Unknown browser URLs default to anonymization when domain exclusions are configured.
- **Incremental semantic indexing:** append and rebuild affected dates instead of clearing the entire index. Optional background indexing remains disabled by default.
- **Read-only bot questions:** an optional, locally configured natural-language mode for authorized Telegram, Feishu, DingTalk, and WeCom senders, with rate and concurrency limits. No write or web tools are available in this mode.
- **Workflow integrations:** focus and context-switch metrics, local Git commit references in daily reports, Obsidian frontmatter and managed-section export, per-task model routing, and additional Agent tools for reports, summaries, projects, and todos.

### Privacy and security

- WebDAV sync v2 uploads only allowed preferences and monotonically strengthens privacy rules. API keys, passwords, bot tokens, model endpoints, and local cleanup permissions are excluded; legacy remote snapshots are scrubbed.
- Local API, MCP, assistant tools, reports, and exported activity data apply current privacy rules. OCR, screenshot paths, executable paths, and activity search snippets are restricted by default.
- Windows screenshot masking blacks out protected visible windows before saving, OCR, or upload; failed masking skips the capture. macOS and Linux retain foreground-application filtering.
- Feishu, DingTalk, and WeCom require sender binding. Bot pipelines share authorization, replay protection, deduplication, quotas, and bounded routing.
- Hardened SSRF checks, redirect handling, token redaction, export paths, dates, WebView navigation, CSP, frontend permissions, and external links.

### Performance and reliability

- SQLite WAL read connections, bounded indexed queries, incremental vacuum, and targeted invalidation reduce database work and lock contention.
- Blocking I/O and image work move out of shared state locks and async workers. Windows OCR and browser UI Automation reuse dedicated workers and caches.
- Screenshot hashing, thumbnail caching, capture merging, idle sampling, activity-tail accounting, background supervision, and Rust-side automatic reports reduce overhead and improve continuity.
- The Rust entry point is split into focused modules. The frontend moves to Svelte 5 with component behavior tests and AST-based security checks.

### Fixes

- Obsidian section export stops if an existing note cannot be read and uses atomic replacement, preserving handwritten content on read or write failure.
- Privacy changes atomically clear hourly summaries and every language's weekly/monthly cache; cleanup failure aborts configuration saving, and generation cannot write back results from outdated privacy rules.
- Updated provider defaults: OpenAI `gpt-6.2-sol`, Gemini `gemini-4-hydrogen`, DeepSeek `deepseek-flash`, Qwen `qwen3.8-flash`, Kimi `kimi-k3`, and MiniMax `MiniMax-M3.1-Flash`. OpenAI reasoning requests use compatible token/sampling parameters and task-specific budgets. Empty AI report responses fall back to the base template with a reason.
- Fixed UTF-8 streaming boundaries, WeCom padding, daylight-saving scheduling, timeline thumbnail refresh, polling-interval persistence, and stale full-configuration writes.

### Compatibility and validation

- SQLite schema advances to `user_version = 3`. New backups cannot be restored directly into older clients. Upgrade every device before enabling WebDAV v2 sync; older clients reject the new envelope and may still upload secrets.
- Feishu, DingTalk, and WeCom senders must bind before querying. Automatic semantic indexing and bot natural-language questions remain off by default. Metadata cleanup remains opt-in.
- Existing installations can opt into test updates on About. Portable and Linux users update from the selected release page; preserve the portable `Data` directory when replacing the executable.
- Local Windows checks passed: 795 Node tests, 20 component tests, 905 Rust tests, type checking, frontend production build, formatting, and Clippy with warnings denied. Two Rust tests remain ignored. Release artifacts must pass this tag's five-platform build, signature, and attachment gates.
- Installation/upgrades, portable startup on another computer, long-running OCR/capture, real Windows standby, and macOS/Linux desktop interaction still require testing. macOS remains ad-hoc signed and may require permissions again after updating.
- Screenshot masking is Windows-only and has documented transparent-overlay limits. Bot group replies remain visible to the group. Search queries still reach the configured search service, and proxy redirects retain the documented address-check limitation.
