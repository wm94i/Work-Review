# Work_Review v1.1.4-rc.1（繁體中文）

1.1.4 的第一個候選版本，僅供測試，不取代正式版 `1.1.3` 的 Latest，也不進入預設正式版自動更新通道。首次試用請從發布頁手動下載安裝；安裝後可在關於頁主動啟用「接收測試版」，接收後續較新的候選版本。安裝前請備份資料，建議使用可捨棄資料驗證升級與清理邊界。

### 修復
- **測試版選擇與確認**：加入預設關閉的緊湊選項，繼續共用一個檢查按鈕。手動更新先確認完整版本，測試版額外提示不穩定風險與備份。正確比較 RC 序號及正式版本，禁止降級，代理下載固定至已確認的 tag；執行檔、安裝程式和更新清單使用相同的完整候選版本號。
- **更新包完整性**：保留 Tauri 簽章驗證，在執行安裝程式前額外比對 GitHub 官方 HTTPS API 提供的目標資產 SHA-256。代理不能只改版本及網址就回放舊的有效簽章包；缺少或不符的官方摘要會拒絕安裝，不信任代理自行提供的摘要。
- **關於頁更新入口**：移除獨立三欄面板、重複版本、通道標籤及說明展開，保留品牌、原有操作、自動檢查選項、進度與失敗回饋。
- **Windows 待機時長**（#189）：監聽睡眠／恢復及目前會話顯示狀態，以獨立取樣和雙時鐘檢查補強；只結算中斷前連續觀察的正常尾段，不把未知空檔算成工作。新建、合併、關閉截圖及浮動視窗計時遵守相同邊界，跨待機的截圖會捨棄。
- **日報編輯字型**（#188）：預設繼承介面字型，在外觀設定提供常用比例字型及等寬字型；未安裝字型時回退至介面字型。
- **GNOME Wayland 空閒偵測**（#187）：優先查詢 Mutter IdleMonitor，保留其他桌面的回退方式。
- **活動 API 隱私**：清單與單筆查詢統一套用隱私規則，非法日期不再擴大為全庫查詢；本機 API 加入請求讀取逾時與並行連線上限。
- **資料可靠性**：切換資料目錄先建立暫存副本，保留目標舊資料的恢復路徑；資料庫遷移不再吞掉真實錯誤，活動回補失敗不再偽裝成功。編輯昨日回退日報使用實際報告日期與快取項目。
- **截圖與儲存**：截圖移出全域狀態鎖，外部命令限制等待時間；刪除到期或超量的本機影像時同步清除資料庫舊路徑，保留遠端 URL。S3 與 WebDAV 禁止公網明文 HTTP，保留本機及私有網路 HTTP。
- **Linux 背景開銷**：空閒偵測共用短期快取，外部命令有逾時；降低鎖定偵測與桌寵視窗取樣頻率、減少重複程序查詢，以及關閉桌寵後的輸入橋接／重試喚醒。
- **查詢與介面回饋**：瀏覽器 URL 加入正規化索引，AI 分類在單批次重用歷史讀取，刪除重複時間線預載。分頁、概覽分類及日報週條失敗不再假裝沒有資料；窄視窗導覽補可存取名稱及目前頁語意。
- **門檻與文件**：每個 PR 及 main push 執行相依安全審計，更新 TLS 信任相關套件，修正 Windows 產物路徑，發布前校驗五處版本來源。

### 安全預設與驗證邊界
- 不會自動改寫已經誤記的歷史時長；#189 回報的異常應用名稱仍需獨立資料核查，不能視為一併解決。
- 自動測試、建置及原生通知註冊檢查不等於真實 S0/S3 待機或安裝升級驗收；多平台長時間桌面互動仍待測試，見 [待機驗收步驟](../testing/windows-standby.md)。部分全域輸入 Hook 關閉後仍採忽略事件，而非全部實體註銷。
- 官方摘要缺失、GitHub API 無法連線或限流時停止線上安裝，不會降低信任改用代理摘要；可稍後重試或從發布頁手動下載。Linux 目前仍由對應發布頁手動安裝。
- macOS 仍為 ad-hoc 簽章，更新後可能需重新授予權限；#177 的卡死恢復後桌寵繪製異常尚未確認解決。
- 中繼資料自動清理仍預設關閉，`0` 天表示永久保留，WebDAV 同步不覆蓋本機清理授權與期限。

### macOS 安裝說明
首次開啟若提示「已損壞，無法開啟」，請執行：

```bash
sudo xattr -rd com.apple.quarantine '/Applications/Work Review.app'
```
