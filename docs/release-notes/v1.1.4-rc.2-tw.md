# Work_Review v1.1.4-rc.2（繁體中文）

1.1.4 的第二個候選版本，彙整 rc.1 後的 Windows 便攜模式、桌寵透明恢復與資料遷移保護。僅供測試，不取代正式版 `1.1.3` 的 Latest，不改寫已發布的 `v1.1.4-rc.1`。安裝／遷移前請先完整備份資料。

### 新增
- **Windows 便攜資料目錄**（#182）：便攜 ZIP 自帶空 `Data` 目錄，EXE 同級存在該目錄時，資料庫、設定、截圖和更新設定優先存放其中，不讀取或改寫本機目錄偏好，也不自動匯入舊資料；沒有標記時保留原有行為。目錄無法讀寫時明確失敗，不默默回退，不新增設定頁面。
- **便攜版更新保護**：仍可檢查正式版和測試版，但只開啟對應發布頁手動下載 ZIP，後端拒絕執行安裝版更新程式。退出後替換 EXE、保留原 `Data`；便攜模式禁止遷移至外部目錄，避免重新啟動後切回另一份資料。打包僅攜帶程式、說明與空 `Data`，不會夾帶既有使用者資料。

### 修復
- **Windows 桌寵亮屏黑塊**（#190）：亮屏／恢復及重新開啟桌寵時，在 GUI 執行緒恢復既有視窗的原生透明合成。合併相鄰通知，再次熄屏或桌寵已隱藏時跳過；不重建 WebView、不改變氣泡樣式、位置、尺寸或滑鼠穿透，恢復動作不搶焦點，也不增加常駐輪詢。已針對可重現的原生透明狀態遺失機制完成修復；真實熄屏及回報者裝置驗收仍需獨立確認。
- **目錄遷移回滾備份**：回滾受阻時保留尚未恢復的目標舊資料，並回報備份路徑；只有確認完整恢復後才刪除空備份目錄，避免極端失敗分支遞迴刪除唯一備份。

- **發布前安全相依升級**：統一使用 `rusqlite 0.41.1` / `libsqlite3-sys 0.39.1`，內建 SQLite 升至 `3.54.1`，修復開啟惡意資料庫／WAL 檔案組合時可能洩漏未初始化記憶體的問題（RUSTSEC-2026-0459）。OpenSSL Rust 綁定更新至 `0.10.80`，修復 OCSP URL 非法 UTF-8 及 AES key-wrap 緩衝區大小校驗問題（RUSTSEC-2026-0474／0476／0477）。不改變應用程式資料庫結構；新增舊版 SQLite 合成資料庫、已提交 WAL、舊表遷移、統計、備份與重新開啟回歸，保留查詢上限溢位時的錯誤行為。

### 更新與便攜使用
- 已安裝 rc.1 的使用者可在關於頁啟用 **「接收測試版」**，使用原有檢查按鈕接收 rc.2；測試更新仍需確認，Windows 安裝版及 macOS 保留簽章與官方 SHA-256 校驗。Linux 和便攜模式使用對應發布頁手動更新。
- 正式版 `1.1.3` 使用者若要試用，需要首次手動下載安裝；未選擇測試版的使用者不會自動升級至此 RC。
- 首次切換便攜模式不會自動搬移歷史。請先完整退出舊程式、備份原資料目錄，再將所需的完整資料副本放入 `Data`。移動時攜帶 EXE 和整個 `Data`；更新時不要用空目錄覆蓋既有 `Data`。
- WebView2 快取、自動啟動註冊及使用者選擇的外部匯出路徑仍由系統管理，不承諾零系統痕跡。`Data` 可能包含 API Key，請勿公開分享。

### 驗證與已知邊界
- 本機前端 775 項、Rust workspace 765 項測試通過，Windows 原生電源通知註冊／註銷另行通過；Windows 除錯建置及 macOS ARM 交叉型別檢查通過，後者不代表真實連結或打包。
- 原生故障注入直接編譯正式恢復模組，24 步通過，涵蓋「黑底→恢復透明」、100 次通知合併為 1 次、隱藏／再次熄屏保護，以及焦點、視窗邊界和穿透維持。**這不是真實熄屏重現**，不能據此認定回報者特定驅動程式的觸發原因，見 [桌寵透明恢復驗收](../testing/windows-avatar-transparency.md)。
- #189 的活動計時保護繼續保留，真實 S0/S3 待機驗收仍待回饋；既有錯誤歷史不會自動重算。#177 的卡死後繪製異常不能視為一併解決。
- 便攜目錄移動／資料讀取及套件內容已有自動驗證；跨電腦實際啟動、安裝升級、長時間運行及多平台桌面驗收仍未完整涵蓋。
- macOS 仍採 ad-hoc 簽章，可能需重新授權；仍有上游未維護／unsound 及撤回版本告警與既有平台限制，不能將安全門檻通過視為所有相依告警已清零。中繼資料自動清理繼續預設關閉，`0` 天表示永久保留。
